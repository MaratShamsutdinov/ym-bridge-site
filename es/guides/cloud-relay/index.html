Haz scrobbling cuando Last.fm no esté disponible directamente

Cloud relay es un respaldo opcional para redes que no pueden alcanzar directamente la API de Last.fm. Activarlo no sustituye el envío directo normal.

El envío directo sigue siendo prioritario

La opción Use Cloud relay for scrobbles when direct delivery is unavailable significa exactamente eso: YM Bridge prueba primero la API de Last.fm desde Chrome. El relay solo recibe scrobbles tras un fallo de red directo que permite usar el respaldo.

Cuando el acceso directo funciona, el panel muestra Delivery target: direct to Last.fm y el relay no se usa para esos scrobbles.

Activa el respaldo

  1. Abre Extension settings y busca Cloud relay.
  2. Activa Use Cloud relay for scrobbles when direct delivery is unavailable.
  3. La primera vez, lee el aviso de uso de datos y pulsa Accept and keep relay fallback. El respaldo no comienza hasta que aceptes la revisión.

Puedes desactivar la opción en cualquier momento para exigir solo el envío directo.

Qué recibe el relay

Solo cuando no está disponible el envío directo, los metadatos de las pistas completadas y la clave de sesión de Last.fm se envían por HTTPS al Cloudflare Worker operado por el desarrollador y se reenvían a Last.fm.

El relay no conserva intencionadamente el historial, las claves de sesión ni el cuerpo de las solicitudes. Cloudflare puede tratar la dirección IP y metadatos técnicos como proveedor de infraestructura. La información completa está en la Política de privacidad.

Lotes y recuperación automática

Los scrobbles de respaldo entran en cola y normalmente se envían en un lote tras 10 pistas o 30 minutos. Así se reduce el tráfico por el Worker. El panel marca estos elementos como Relay y los mantiene visibles en la cola.

YM Bridge comprueba periódicamente el acceso directo a Last.fm. Cuando vuelve a estar disponible, los nuevos envíos regresan automáticamente a la ruta directa sin borrar la opción de relay.

Comprueba que funciona

  • Abre el panel lateral y consulta Delivery target.
  • Abre View queue para ver Relay, Retry o Failed.
  • Si un lote sigue pendiente después de su plazo, pulsa Retry una vez y revisa el error actualizado.
  • La etiqueta connected confirma una sesión guardada de Last.fm, pero no demuestra por sí sola que la API directa sea accesible desde la red actual.
