Datos y privacidad

Política de privacidad

Yandex Music to Last.fm Bridge (Scrobbler). Última actualización: 21 de julio de 2026.

Las traducciones se ofrecen para facilitar la lectura. Si una versión traducida difiere de la inglesa, prevalece la versión en inglés.

Esta política describe cómo la extensión de Chrome trata los datos para ofrecer controles de Yandex Music, funciones de Last.fm, exportaciones locales y diagnóstico.

Datos tratados

La extensión puede tratar:

  • metadatos de pistas de Yandex Music, como artista, título, álbum, URL de la carátula, duración, posición y estado de reproducción, y estado de Me gusta o No me gusta;
  • marcas de tiempo de escucha, elementos de la cola local de scrobbles, estado de reintentos y resultados de entrega;
  • nombre de usuario, perfil, estadísticas de escucha, clave de sesión y respuestas de Last.fm cuando hay una cuenta conectada;
  • configuración de la extensión, tema seleccionado, preferencias de control y de exportación local;
  • una clave de firma generada localmente, un identificador de instalación derivado, la hora de la solicitud, un nonce y el hash del cuerpo utilizados para autenticar solicitudes al servicio YM Bridge.

Controles de Yandex Music

La información de reproducción se lee de la página abierta de Yandex Music para mostrar la pista actual y ejecutar los controles solicitados por el usuario. Solo se guarda localmente cuando es necesario para el estado actual, la cola, el diagnóstico o las exportaciones elegidas por el usuario.

Modo directo de Last.fm

Cuando Last.fm está conectado y el envío directo está disponible, los metadatos de la pista, la clave de sesión de Last.fm y las solicitudes API se envían directamente a Last.fm. El perfil y las estadísticas mostrados también se solicitan directamente a Last.fm. La clave de sesión y el estado en caché se guardan en el almacenamiento de la extensión de Chrome.

Servicio YM Bridge y Cloud relay opcional

La extensión contacta con ym-bridge.mytunnel.us.com para obtener la configuración de su aplicación de Last.fm y autenticar versiones compatibles. Las solicitudes incluyen un identificador de instalación derivado, clave pública de firma, hora, nonce, hash del cuerpo y firma. El servicio usa estos datos técnicos para autenticar solicitudes, impedir repeticiones y limitar abusos.

Al pulsar Connect Last.fm se intenta primero la autenticación directa desde el navegador. Si la API directa de autenticación de Last.fm no está disponible, el servicio puede solicitar temporalmente un token o canjear el token aprobado por el usuario por una clave de sesión de Last.fm y devolverla a la extensión. Este respaldo de autenticación no cambia la preferencia de Cloud relay. El Worker no conserva intencionadamente el token ni la clave de sesión.

Si el usuario elige el acceso alternativo con nombre de usuario o correo electrónico y contraseña, esas credenciales se envían por HTTPS al YM Bridge relay y se reenvían una sola vez a Last.fm exclusivamente para obtener una clave de sesión. La contraseña no se guarda en el almacenamiento de Chrome, se borra del formulario tras el intento y el relay no la almacena ni registra intencionadamente. La clave de sesión y el nombre de usuario devueltos se guardan localmente. Cloudflare trata la solicitud como proveedor de infraestructura del relay.

Cloud relay para scrobbles está seleccionado de forma predeterminada como respaldo, solo se inicia tras una revisión única del uso de datos dentro de la extensión y se puede desactivar en la configuración. La extensión intenta primero el envío directo a Last.fm. Solo cuando no está disponible se envían por HTTPS los metadatos de pistas completadas y la clave de sesión al Cloudflare Worker operado por el desarrollador, que los reenvía a Last.fm. Normalmente se envían lotes tras 10 pistas o 30 minutos, mientras la extensión comprueba periódicamente el acceso directo.

El relay no conserva intencionadamente el historial de escucha, las claves de sesión de Last.fm ni los cuerpos de las solicitudes. Cloudflare, como proveedor de infraestructura, puede tratar direcciones IP y metadatos técnicos conforme a sus propias políticas y periodos de conservación.

Almacenamiento local y conservación

La configuración, los datos de sesión de Last.fm, las claves de firma, el perfil y las estadísticas en caché, la cola de scrobbles y el estado de envío se guardan en el perfil de Chrome. Los elementos de la cola se eliminan durante el envío y la gestión normales. El usuario puede borrar la sesión de Last.fm, desactivar las exportaciones, eliminar los elementos fallidos o desinstalar la extensión para borrar su almacenamiento.

Exportación de archivos Now Playing

La exportación opcional Now Playing escribe el texto de la pista, datos JSON y una carátula en una carpeta solo después de que el usuario conceda acceso explícito. Los archivos permanecen en el dispositivo y el usuario puede desactivar la función o eliminarlos.

Portapapeles

El permiso para escribir en el portapapeles solo se usa después de una acción directa sobre un comando de copia. Puede escribir el texto de la pista actual, la URL de una carátula o su imagen. La extensión no lee el portapapeles ni escribe automáticamente.

Companion de escritorio opcional

El companion de escritorio opcional se comunica mediante localhost o 127.0.0.1 solo para mostrar avisos de pistas. La extensión sigue siendo responsable del envío a Last.fm.

Cesión y venta de datos

Los datos del usuario no se venden. Solo se comunican cuando es necesario para la función elegida:

  • a Last.fm para autenticación, solicitudes de perfil y estadísticas, actualizaciones de now playing y scrobbling;
  • a la infraestructura de Cloudflare para solicitudes al servicio YM Bridge y el envío opcional por relay;
  • al companion local cuando se activan explícitamente los avisos de pistas;
  • a archivos locales o al portapapeles tras una acción explícita del usuario.

Análisis y publicidad

La extensión no contiene SDK publicitarios, seguimiento de comportamiento ni análisis de producto. Los datos no se usan para publicidad, solvencia ni perfiles sin relación con sus funciones. Chrome Web Store puede facilitar al editor análisis agregados de la ficha de la tienda; esto no añade código de análisis a la extensión.

Seguridad

Las solicitudes remotas usan HTTPS. Los endpoints protegidos de YM Bridge exigen solicitudes firmadas y comprueban la hora, el nonce, el ID de la extensión y los límites de frecuencia. Ningún control garantiza protección absoluta, pero estas medidas limitan solicitudes no autorizadas y repetidas.

Uso limitado

El uso de información recibida de las API de Google cumplirá la Política de Datos de Usuario de Chrome Web Store, incluidos los requisitos de Uso limitado. Los datos solo se usan para ofrecer o mejorar las funciones visibles declaradas de la extensión.

Cambios y contacto

Esta página se actualizará antes de publicar cambios importantes en el tratamiento de datos. Para consultas de soporte o privacidad, usa el contacto de la ficha de Chrome Web Store o la página de asistencia.
