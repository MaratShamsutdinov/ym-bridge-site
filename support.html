Support

Support information for Yandex Music to Last.fm Bridge.

Controls stopped working

Open the extension Settings panel, run Control health, then use Repair controls. You can also reload the Yandex Music tab.

Last.fm delivery failed

Check the scrobble queue and retry pending items. If direct Last.fm access is unavailable but the internet connection works, the extension uses Cloud relay as a fallback by default. It can be disabled in Extension settings.

Folder access must be granted again if Chrome loses the saved permission. Open Settings and choose the export folder.

Contact

Use the developer contact or support link on the Chrome Web Store listing. Include the copied Control health diagnostics, but remove anything you do not want to share.
