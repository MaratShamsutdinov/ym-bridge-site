Assistance

Aide pour Yandex Music to Last.fm Bridge.

Les commandes ne fonctionnent plus

Ouvrez les paramètres de l'extension, lancez Control health, puis utilisez Repair controls. Vous pouvez également actualiser l'onglet Yandex Music.

Échec de l'envoi vers Last.fm

Vérifiez la file de scrobbles et relancez les éléments en attente. Si l'accès direct à Last.fm est indisponible malgré une connexion Internet fonctionnelle, l'extension utilise Cloud relay comme solution de secours par défaut. Vous pouvez le désactiver dans les paramètres.

Guides pas à pas

Consultez les guides détaillés pour le compte, le secours réseau et le diagnostic de la file.

Installer et connecter Last.fm Utiliser Cloud relay lorsque Last.fm est inaccessible directement Comprendre et relancer la file de scrobbles Découvrir les dispositions du mini-lecteur et du panneau latéral Contrôler la lecture avec des raccourcis clavier Exporter les fichiers Now Playing pour OBS

Fichiers Now Playing

L'accès au dossier doit être accordé de nouveau si Chrome perd l'autorisation enregistrée. Ouvrez les paramètres et choisissez le dossier d'exportation.

Contact

Utilisez le contact du développeur ou le lien d'assistance sur la fiche du Chrome Web Store. Joignez le diagnostic Control health copié, après avoir retiré toute information que vous ne souhaitez pas partager.
