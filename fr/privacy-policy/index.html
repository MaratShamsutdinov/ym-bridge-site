Données et confidentialité

Politique de confidentialité

Yandex Music to Last.fm Bridge (Scrobbler). Dernière mise à jour : 21 juillet 2026.

Les traductions sont proposées pour faciliter la lecture. En cas de divergence, la version anglaise prévaut.

Cette politique explique comment l'extension Chrome traite les données afin de fournir les commandes Yandex Music, les fonctions Last.fm, les exportations locales et les diagnostics.

Données traitées

L'extension peut traiter :

  • les métadonnées des titres Yandex Music, dont l'artiste, le titre, l'album, l'URL de la pochette, la durée, la position et l'état de lecture ainsi que l'état J'aime ou Je n'aime pas ;
  • les horodatages d'écoute, les éléments de la file locale de scrobbles, l'état des nouvelles tentatives et les résultats d'envoi ;
  • le nom d'utilisateur, les informations de profil, les statistiques d'écoute, la clé de session et les réponses Last.fm lorsqu'un compte est connecté ;
  • les paramètres de l'extension, le thème choisi, les préférences de commande et d'exportation locale ;
  • une clé de signature générée localement, un identifiant d'installation dérivé, l'heure de la requête, un nonce et le hachage du corps servant à authentifier les requêtes adressées au service YM Bridge.

Commandes Yandex Music

Les informations de lecture sont lues sur la page Yandex Music ouverte afin d'afficher le titre en cours et d'exécuter les commandes demandées par l'utilisateur. Elles ne sont conservées localement que lorsque cela est nécessaire pour l'état actuel, la file, les diagnostics ou les exportations choisies.

Mode direct Last.fm

Lorsque Last.fm est connecté et que l'envoi direct est disponible, les métadonnées du titre, la clé de session Last.fm et les requêtes API sont envoyées directement à Last.fm. Le profil et les statistiques affichés sont également demandés directement à Last.fm. La clé de session et l'état mis en cache sont conservés dans le stockage de l'extension Chrome.

Service YM Bridge et Cloud relay facultatif

L'extension contacte ym-bridge.mytunnel.us.com pour obtenir la configuration de son application Last.fm et authentifier les versions prises en charge. Les requêtes incluent un identifiant d'installation dérivé, une clé publique de signature, l'heure, un nonce, le hachage du corps et une signature. Le service utilise ces données techniques pour authentifier les requêtes, empêcher leur rejeu et limiter les abus.

Lorsque l'utilisateur choisit Connect Last.fm, l'authentification directe depuis le navigateur est tentée en premier. Si l'API directe de Last.fm est indisponible, le service peut demander temporairement un jeton ou échanger le jeton approuvé par l'utilisateur contre une clé de session Last.fm et la renvoyer à l'extension. Ce secours d'authentification ne modifie pas la préférence Cloud relay. Le Worker ne conserve pas intentionnellement le jeton ni la clé de session.

Si l'utilisateur choisit l'autre connexion par nom d'utilisateur ou e-mail et mot de passe, ces identifiants sont envoyés par HTTPS au YM Bridge relay puis transmis une seule fois à Last.fm, uniquement pour obtenir une clé de session. Le mot de passe n'est pas stocké dans Chrome, est effacé du formulaire après la tentative et n'est ni conservé ni journalisé intentionnellement par le relay. La clé de session et le nom d'utilisateur renvoyés sont stockés localement. Cloudflare traite la requête en tant que fournisseur d'infrastructure du relay.

Cloud relay pour les scrobbles est sélectionné par défaut comme solution de secours, ne démarre qu'après une présentation unique de l'utilisation des données dans l'extension et peut être désactivé. L'extension tente toujours d'abord l'envoi direct à Last.fm. Seulement si celui-ci est indisponible, les métadonnées des titres terminés et la clé de session sont envoyées par HTTPS au Cloudflare Worker exploité par le développeur, puis transmises à Last.fm. Les lots sont généralement envoyés après 10 titres ou 30 minutes, tandis que l'extension vérifie périodiquement l'accès direct.

Le relay ne conserve pas intentionnellement l'historique d'écoute, les clés de session Last.fm ou le corps des requêtes. Cloudflare, en tant que fournisseur d'infrastructure, peut traiter les adresses IP et les métadonnées techniques selon ses propres politiques et pratiques de conservation.

Stockage local et conservation

Les paramètres, données de session Last.fm, clés de signature, données de profil et statistiques mises en cache, éléments de la file de scrobbles et état d'envoi sont stockés dans le profil Chrome. Les éléments de la file sont supprimés dans le cadre de l'envoi et de la gestion habituels. L'utilisateur peut effacer la session Last.fm, désactiver les exportations, supprimer les éléments en échec ou retirer l'extension pour effacer son stockage.

Exportation des fichiers Now Playing

L'exportation facultative Now Playing écrit le texte du titre, les données JSON et une pochette dans un dossier seulement après l'autorisation explicite de l'utilisateur. Les fichiers restent sur son appareil et peuvent être désactivés ou supprimés.

Presse-papiers

L'autorisation d'écrire dans le presse-papiers n'est utilisée qu'après une action directe sur une commande de copie. Elle peut écrire le texte du titre actuel, l'URL d'une pochette ou son image. L'extension ne lit pas le presse-papiers et n'y écrit pas automatiquement.

Companion de bureau facultatif

Le companion de bureau facultatif communique via localhost ou 127.0.0.1 uniquement pour afficher les notifications de titres. L'extension reste responsable de l'envoi à Last.fm.

Partage et vente des données

Les données utilisateur ne sont pas vendues. Elles ne sont communiquées que dans la mesure nécessaire à la fonction choisie :

  • à Last.fm pour l'authentification, les demandes de profil et de statistiques, les mises à jour now playing et le scrobbling ;
  • à l'infrastructure Cloudflare pour les requêtes au service YM Bridge et l'envoi facultatif par relay ;
  • au companion local lorsque les notifications de titres sont explicitement activées ;
  • aux fichiers locaux ou au presse-papiers après une action explicite de l'utilisateur.

Analyse et publicité

L'extension ne contient aucun SDK publicitaire, suivi comportemental ou outil d'analyse produit. Les données ne servent pas à la publicité, à l'évaluation de solvabilité ou à un profilage sans rapport. Le Chrome Web Store peut fournir à l'éditeur des analyses agrégées sur la fiche du Store ; cela n'ajoute aucun code d'analyse à l'extension.

Sécurité

Les requêtes distantes utilisent HTTPS. Les points d'accès YM Bridge protégés exigent des requêtes signées et vérifient l'heure, le nonce, l'identifiant de l'extension et les limites de fréquence. Aucune mesure ne garantit une protection absolue, mais ces contrôles limitent les requêtes non autorisées et rejouées.

Utilisation limitée

L'utilisation des informations reçues via les API Google respecte la politique sur les données utilisateur du Chrome Web Store, y compris les exigences d'utilisation limitée. Les données servent uniquement à fournir ou améliorer les fonctions déclarées et visibles de l'extension.

Modifications et contact

Cette page sera mise à jour avant la publication de toute modification importante du traitement des données. Pour les questions d'assistance ou de confidentialité, utilisez les coordonnées de la fiche Chrome Web Store ou la page d'assistance.
