Guide de livraison

Scrobbler lorsque Last.fm est inaccessible directement

Cloud relay est un secours facultatif pour les réseaux qui ne peuvent pas joindre directement l'API Last.fm. Son activation ne remplace pas l'envoi direct normal.

La livraison directe reste prioritaire

Le réglage Use Cloud relay for scrobbles when direct delivery is unavailable est littéral: YM Bridge essaie d'abord l'API Last.fm depuis Chrome. Le relay n'est sollicité qu'après un échec réseau direct admissible au secours.

Lorsque l'accès direct fonctionne, le panneau affiche Delivery target: direct to Last.fm et le relay n'est pas utilisé pour ces scrobbles.

Activez le secours

  1. Ouvrez Extension settings et trouvez Cloud relay.
  2. Activez Use Cloud relay for scrobbles when direct delivery is unavailable.
  3. À la première utilisation, lisez l'avis sur les données et cliquez sur Accept and keep relay fallback. Le secours ne démarre pas avant cette validation.

Vous pouvez désactiver l'option à tout moment afin d'exiger uniquement la livraison directe.

Ce que reçoit le relay

Uniquement quand la livraison directe est indisponible, les métadonnées des titres terminés et la clé de session Last.fm sont envoyées par HTTPS au Cloudflare Worker exploité par le développeur, puis transmises à Last.fm.

Le relay ne conserve volontairement ni historique d'écoute, ni clé de session, ni corps de requête. Cloudflare peut traiter l'adresse IP et les métadonnées techniques en tant que fournisseur d'infrastructure. La description complète se trouve dans la Politique de confidentialité.

Lots et récupération automatique

Les scrobbles de secours sont mis en file et généralement envoyés par lot après 10 titres ou 30 minutes. Cela réduit le trafic via le Worker. Le panneau les marque Relay et les laisse visibles dans la file.

YM Bridge vérifie régulièrement l'accès direct à Last.fm. Quand il revient, les nouvelles livraisons repassent automatiquement par la voie directe sans supprimer le réglage relay.

Vérifiez le fonctionnement

  • Ouvrez le panneau latéral et consultez Delivery target.
  • Ouvrez View queue pour voir Relay, Retry ou Failed.
  • Si un lot reste après son échéance, cliquez une fois sur Retry et consultez l'erreur actualisée.
  • La mention Last.fm connected confirme une session enregistrée, mais ne prouve pas à elle seule que l'API directe est accessible depuis le réseau actuel.
