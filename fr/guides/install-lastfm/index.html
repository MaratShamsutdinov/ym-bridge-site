Guide de configuration

Connecter Yandex Music à Last.fm

YM Bridge lit le titre joué dans un onglet Yandex Music ouvert et envoie les écoutes admissibles à votre compte Last.fm. L'extension conserve le contrôle de la livraison.

Ouvrir dans le Chrome Web Store Assistance
Sur cette page Avant de commencer Connectez votre compte Last.fm Vérifiez la livraison Si la connexion normale est indisponible

Avant de commencer

  • Utilisez Chrome et gardez Yandex Music ouvert dans un onglet.
  • Installez YM Bridge depuis le Chrome Web Store.
  • Préparez un compte Last.fm. Le companion Windows n'est pas nécessaire au scrobbling.

Connectez votre compte Last.fm

  1. Ouvrez le panneau latéral YM Bridge, développez Tools, choisissez Settings, puis Extension settings.
  2. Dans Last.fm setup, cliquez sur Connect Last.fm.
  3. Autorisez l'accès sur Last.fm. L'extension stocke la clé de session renvoyée dans le stockage Chrome.
  4. Revenez au panneau et vérifiez que Last.fm apparaît comme connected.

Vérifiez la livraison

Lancez un titre dans Yandex Music et ouvrez le panneau latéral. Le titre, l'artiste et la cible de livraison doivent apparaître. Avec un accès réseau normal, la cible indique direct to Last.fm.

Une file vide peut être normale pendant le traitement en direct du titre. Après l'envoi d'une écoute admissible, Last delivery est actualisé et le titre apparaît dans votre historique Last.fm.

Si la connexion normale est indisponible

Essayez d'abord Connect Last.fm. Si l'API d'authentification directe est inaccessible, YM Bridge peut terminer l'échange du jeton approuvé via son service.

Le formulaire alternatif avec identifiant ou e-mail et mot de passe n'agit qu'après un clic sur son bouton. Les identifiants sont envoyés une fois par HTTPS afin d'obtenir une clé de session Last.fm; le mot de passe est effacé du formulaire, n'est pas stocké par l'extension et n'est pas volontairement journalisé par le relay. Consultez la Politique de confidentialité pour le flux complet.
