控制功能停止運作

開啟擴充功能設定，執行 Control health，然後使用 Repair controls。也可以重新載入 Yandex Music 分頁。

Last.fm 傳送失敗

檢查播放記錄佇列並重試待處理項目。如果網際網路連線正常但無法直接存取 Last.fm，擴充功能預設會使用 Cloud relay 作為備援。可在擴充功能設定中關閉。

逐步指南

透過詳細指南完成帳戶設定、網路備援和佇列診斷。

安裝並連接 Last.fm 無法直連 Last.fm 時使用 Cloud relay 了解並重試播放記錄佇列 瀏覽迷你播放器和側邊欄版面 使用鍵盤快速鍵控制播放 為 OBS 匯出 Now Playing 檔案

Now Playing 檔案

如果 Chrome 遺失已儲存的權限，需要重新授予資料夾存取權限。開啟設定並選擇匯出資料夾。

聯絡方式

請使用 Chrome 線上應用程式商店頁面上的開發者聯絡方式或支援連結。請附上複製的 Control health 診斷資訊，並移除您不想分享的內容。
