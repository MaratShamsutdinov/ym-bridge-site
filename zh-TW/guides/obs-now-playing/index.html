授予資料夾存取權

在側邊欄中展開 Tools，選擇 Settings，然後在 Now Playing files 區域按 Grant folder access。選擇一個 OBS 可以持續讀取的專用資料夾。

擴充功能不能代替您選擇資料夾，因此 Chrome 會直接要求確認。權限僅保留在本機，可透過 Change folder 變更，或透過 Disable Now Playing 移除。

YM Bridge 寫入的檔案

now-playing.txt 為 OBS 文字來源儲存一行演出者和曲目名稱。now-playing.json 為自訂疊加層提供結構化中繼資料。啟用封面匯出後，now-playing-cover.png 會隨目前封面更新。

曲目變更時，同一位置的檔案會被取代，並始終留在您的電腦上。Last.fm 傳送和選用的桌面 companion 是獨立功能。

將輸出加入 OBS

  1. 新增 Text (GDI+) 來源，啟用從檔案讀取，然後選擇 now-playing.txt。
  2. 為 now-playing-cover.png 新增一個 Image 來源。
  3. 在場景中設定兩個來源的樣式和位置。擴充功能不需控制 OBS，OBS 也會偵測後續檔案變更。

如果疊加層需要分別使用演出者、標題、專輯或封面，請使用 JSON 檔案。

檢查匯出狀態

開啟 Control health，查看 Now Playing files 一列。writing - just now 表示剛完成更新；permission needed 表示需要在 Chrome 中重新授權資料夾。

如果曲目資料本身已過期，請執行 Repair controls 並重新載入 Yandex Music 分頁。資料夾權限無法修復失效的頁面連線。
