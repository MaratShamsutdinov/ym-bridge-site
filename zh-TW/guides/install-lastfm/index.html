將 Yandex Music 連接到 Last.fm

YM Bridge 會讀取已開啟 Yandex Music 分頁中的曲目，並將符合條件的收聽記錄傳送至您的 Last.fm 帳戶。傳送仍由擴充功能管理。

開始之前

  • 使用 Chrome，並在分頁中保持 Yandex Music 開啟。
  • 從 Chrome 線上應用程式商店安裝 YM Bridge。
  • 準備好 Last.fm 帳戶。播放記錄提交不需要 Windows companion。

連接 Last.fm 帳戶

  1. 開啟 YM Bridge 側邊欄，展開 Tools，選擇 Settings，再開啟 Extension settings。
  2. 在 Last.fm setup 中按下 Connect Last.fm。
  3. 在 Last.fm 核准存取。擴充功能會將傳回的工作階段金鑰儲存在 Chrome 擴充功能儲存空間。
  4. 返回面板，確認 Last.fm 顯示為 connected。

驗證傳送

在 Yandex Music 播放曲目並開啟側邊欄。應顯示曲名、藝術家和傳送目標。網路正常時，目標為 direct to Last.fm。

目前曲目正在即時處理時，佇列為空也可能是正常狀態。符合條件的收聽記錄送出後，Last delivery 會更新，曲目也會出現在 Last.fm 記錄中。

無法使用一般登入時

請先嘗試 Connect Last.fm。如果無法連接直接驗證 API，YM Bridge 可以透過其服務完成已核准權杖的交換。

只有按下按鈕後，使用使用者名稱或電子郵件和密碼的備援表單才會執行。憑證僅透過 HTTPS 傳送一次以取得 Last.fm 工作階段金鑰；密碼會從表單清除，不由擴充功能儲存，也不會被 relay 刻意記錄。完整流程請參閱隱私權政策。
