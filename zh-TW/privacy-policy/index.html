資料與隱私權

隱私權政策

Yandex Music to Last.fm Bridge（Scrobbler）。最後更新：2026年7月21日。

翻譯僅為方便閱讀而提供。如果翻譯版本與英文版本有差異，以英文版本為準。

本政策說明 Chrome 擴充功能如何處理資料，以提供 Yandex Music 控制、Last.fm 功能、本機匯出和診斷。

處理的資料

擴充功能可能會處理：

  • Yandex Music 曲目中繼資料，包括藝術家、標題、專輯、封面網址、時長、播放位置與狀態，以及喜歡或不喜歡狀態；
  • 收聽時間、本機播放記錄佇列項目、重試狀態和傳送結果；
  • 連接 Last.fm 帳戶時的使用者名稱、個人資料資訊、收聽統計、工作階段金鑰和 Last.fm 回應；
  • 擴充功能設定、所選主題、控制偏好和本機匯出偏好；
  • 用於驗證 YM Bridge 服務要求的本機產生簽署金鑰、衍生安裝識別碼、要求時間、nonce 和本文雜湊。

Yandex Music 控制

擴充功能從已開啟的 Yandex Music 頁面讀取播放資訊，以顯示目前曲目並執行使用者要求的控制。只會在目前狀態、佇列、診斷或使用者選擇的匯出需要時儲存在本機。

Last.fm 直接模式

連接 Last.fm 且可直接傳送時，曲目中繼資料、Last.fm 工作階段金鑰和 API 要求會直接傳送到 Last.fm。顯示的個人資料和收聽統計也直接向 Last.fm 要求。工作階段金鑰和快取的擴充功能狀態儲存在 Chrome 擴充功能儲存空間中。

YM Bridge 服務和可選 Cloud relay

擴充功能會連接 ym-bridge.mytunnel.us.com，以取得 Last.fm 應用程式設定並驗證支援的擴充功能版本。要求包含衍生安裝識別碼、公開簽署金鑰、時間、nonce、本文雜湊和簽章。服務使用這些技術資料驗證要求、防止重播並限制濫用。

使用者按下 Connect Last.fm 後，會先嘗試透過瀏覽器直接驗證。如果 Last.fm 直接驗證 API 無法使用，服務可能暫時要求驗證權杖，或將使用者核准的權杖換取 Last.fm 工作階段金鑰並傳回擴充功能。這個備援驗證不會變更 Cloud relay 偏好。Worker 不會刻意保留權杖或工作階段金鑰。

如果使用者選擇以使用者名稱或電子郵件和密碼進行備用登入，這些認證資料會透過 HTTPS 傳送到 YM Bridge relay，並且只為取得 Last.fm 工作階段金鑰而向 Last.fm 轉送一次。密碼不會儲存在 Chrome 中，嘗試後會從表單清除，relay 也不會刻意儲存或記錄密碼。傳回的工作階段金鑰和使用者名稱儲存在本機。Cloudflare 作為 relay 基礎設施供應商處理要求。

用於播放記錄提交的 Cloud relay 預設選為備援通道，但只有在擴充功能內完成一次性資料使用說明確認後才會啟動，並可在設定中關閉。擴充功能一律優先嘗試直接傳送到 Last.fm。只有無法直接傳送時，才會透過 HTTPS 將已完成曲目的中繼資料和工作階段金鑰傳送到開發者營運的 Cloudflare Worker，再轉送到 Last.fm。通常每10首曲目或30分鐘批次傳送一次，同時擴充功能會定期檢查直接存取。

relay 不會刻意保留收聽記錄、Last.fm 工作階段金鑰或要求本文。Cloudflare 作為基礎設施供應商，可能依照自身政策和保留做法處理 IP 位址和技術要求中繼資料。

本機儲存和保留

設定、Last.fm 工作階段資料、簽署金鑰、快取的個人資料和統計、播放記錄佇列項目及傳送狀態儲存在 Chrome 設定檔中。佇列項目會在正常傳送和管理過程中移除。使用者可以清除 Last.fm 工作階段、關閉匯出、刪除失敗項目或移除擴充功能以刪除其儲存資料。

Now Playing 檔案匯出

可選的 Now Playing 匯出只會在使用者明確授予資料夾存取權限後，才將曲目文字、JSON 資料和封面寫入資料夾。檔案保留在使用者裝置上，使用者可以關閉此功能或刪除檔案。

剪貼簿

剪貼簿寫入權限只會在使用者直接執行複製命令後使用。它可以寫入目前曲目文字、封面網址或封面圖片。擴充功能不會讀取剪貼簿，也不會自動寫入。

可選桌面 companion

可選桌面 companion 只為顯示曲目通知而透過 localhost 或 127.0.0.1 通訊。Last.fm 傳送仍由擴充功能負責。

資料分享與銷售

不會出售使用者資料。只會在所選功能需要時向下列對象提供：

  • 為進行驗證、個人資料和統計要求、now playing 更新及播放記錄提交而提供給 Last.fm；
  • 為處理 YM Bridge 服務要求和可選 relay 傳送而提供給 Cloudflare 基礎設施；
  • 明確啟用桌面曲目通知時提供給本機 companion；
  • 使用者明確操作後寫入本機檔案或剪貼簿。

分析與廣告

擴充功能不包含廣告 SDK、行為追蹤或產品分析。資料不會用於廣告、信用評估或無關的使用者分析。Chrome 線上應用程式商店可能向發布者提供商店頁面的彙總分析；這不會向擴充功能加入分析程式碼。

安全性

遠端要求使用 HTTPS。受保護的 YM Bridge 端點要求簽署要求，並檢查時間、nonce、擴充功能 ID 和頻率限制。沒有任何安全措施能保證絕對保護，但這些控制可限制未經授權和重複的要求。

限制使用

從 Google API 接收的資訊將遵守 Chrome 線上應用程式商店使用者資料政策，包括限制使用要求。資料只用於提供或改善已揭露的使用者功能。

變更與聯絡

如資料處理方式有重大變更，本頁面會在相關版本發布前更新。如有支援或隱私權問題，請使用 Chrome 線上應用程式商店頁面上的聯絡方式或造訪支援頁面。
