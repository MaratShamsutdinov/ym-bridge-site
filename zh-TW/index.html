不只是播放按鈕

可檢查的播放記錄提交

需要時再連接 Last.fm。擴充功能會顯示傳送佇列、重試失敗項目，並在直接連線時提供詳細的收聽統計。

  • 從瀏覽器直接傳送到 Last.fm
  • 無法直接存取時自動使用 Cloud relay 備援；可隨時關閉
  • 佇列狀態、重試和控制診斷
  • 可重新指派的 Chrome 鍵盤快速鍵

播放

播放、暫停、跳轉、調整音量、切換曲目，並在 Yandex Music 提供時管理喜歡或不喜歡狀態。

Now Playing 檔案

明確授予資料夾存取權限後，可將目前曲目寫入 TXT 和 JSON，並可為 OBS 儲存本機封面檔案。

封面操作

開啟封面、複製其網址或圖片，以及從面板或迷你播放器複製 藝術家 - 曲目。

可選 companion

Windows companion 可加入原生曲目切換通知。播放和播放記錄提交仍由擴充功能負責。

實用指南

設定並維持播放記錄提交正常運作

了解如何連接 Last.fm、使用直連優先的 relay 備援，以及解決延遲提交的問題。

01 安裝並連接 Last.fm 授權帳戶、確認已儲存的工作階段，並驗證第一次直接提交。 → 02 無法直連 Last.fm 時使用 Cloud relay 了解何時啟用備援、會傳輸哪些資料，以及 YM Bridge 如何恢復直接傳送。 → 03 了解並重試播放記錄佇列 識別 Pending、Relay、Retry 和 Failed 狀態，不要把目前播放誤認為遺失的曲目。 → 04 瀏覽迷你播放器和側邊欄版面 比較完整介面與 Progress disc、Ambient、Control deck 和 Glass card 檢視。 → 05 使用鍵盤快速鍵控制播放 指派實用的按鍵組合，並選擇可在全域使用的播放指令。 → 06 為 OBS 匯出 Now Playing 檔案 在本機寫入與目前 Yandex Music 曲目同步的 TXT、JSON 和封面檔案。 →
