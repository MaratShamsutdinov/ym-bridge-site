One control surface

Keep the player close

The side panel follows the current Yandex Music track and keeps the controls you use most in one compact view.

Floating controls

Mini player

Open a separate window, resize it from compact controls to a cover-first view, and keep it on another display.

Appearance

Light and dark

Match the panel to your desktop. Album-derived accents keep the current track visible without overwhelming the interface.

More than transport buttons

Scrobbling you can inspect

Connect Last.fm when you need it. The extension keeps a visible delivery queue, retries failed items and shows detailed listening statistics for direct connections.

  • Direct Last.fm delivery from the browser
  • Automatic Cloud relay fallback when direct access is unavailable; it can be disabled
  • Queue states, retries and control-health diagnostics
  • Reassignable Chrome keyboard shortcuts

Playback

Play, pause, seek, adjust volume, switch tracks, and manage like or dislike state when Yandex Music exposes it.

Now Playing files

After explicit folder access, write the current track to TXT and JSON with an optional local cover file for OBS.

Cover actions

Open artwork, copy its URL or image, and copy the current Artist - Track value from the panel or mini player.

Optional companion

The Windows companion adds native track-change popups. Playback and scrobbling remain owned by the extension.

Local-first by default

Your listening setup stays under your control

No ads or product analytics. Settings and the Last.fm session are stored in Chrome extension storage.

Explicit actions. File and clipboard access happen only after you grant access or press the corresponding command.

Controlled network paths. Direct Last.fm delivery is tried first. Cloud relay can be disabled, and the desktop companion is used only when you enable its popup integration.

Optional Windows companion

Native track-change popups

The extension is complete on its own. Install the companion only if you want a small Windows notification window when the track changes.
