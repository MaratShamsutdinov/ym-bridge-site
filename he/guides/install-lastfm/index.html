חיבור Yandex Music ל־Last.fm

YM Bridge קורא את הרצועה שמתנגנת בכרטיסייה פתוחה של Yandex Music ושולח לחשבון Last.fm האזנות שעומדות בתנאי הדיווח. התוסף נשאר אחראי לשליחה.

פתיחה ב־Chrome Web Store תמיכה
בדף זה לפני שמתחילים חיבור חשבון Last.fm בדיקת השליחה אם הכניסה הרגילה אינה זמינה

לפני שמתחילים

  • השתמשו ב־Chrome והשאירו את Yandex Music פתוח בכרטיסייה.
  • התקינו את YM Bridge מ־Chrome Web Store.
  • הכינו חשבון Last.fm. היישום הנלווה ל־Windows אינו נדרש לדיווח האזנות.

חיבור חשבון Last.fm

  1. פתחו את חלונית הצד של YM Bridge, הרחיבו את כלים, בחרו הגדרות ופתחו את הגדרות התוסף.
  2. בקטע הגדרת Last.fm, לחצו על חיבור Last.fm.
  3. אשרו את הגישה ב־Last.fm. התוסף שומר את מפתח ההפעלה שמוחזר באחסון התוסף של Chrome.
  4. חזרו לחלונית וודאו ש־Last.fm מוצג כ־מחובר.

בדיקת השליחה

הפעילו רצועה ב־Yandex Music ופתחו את חלונית הצד. אמורים להופיע שם הרצועה הנוכחית, האמן ויעד השליחה. כאשר הגישה לרשת תקינה, היעד מוצג כ־ישירות ל־Last.fm.

תור ריק עשוי להיות תקין בזמן שהרצועה הנוכחית מטופלת בזמן אמת. לאחר שליחת האזנה שעומדת בתנאי הדיווח, הערך שליחה אחרונה מתעדכן והרצועה מופיעה בהיסטוריית Last.fm שלכם.

אם הכניסה הרגילה אינה זמינה

נסו תחילה את חיבור Last.fm. אם אין גישה לממשק האימות הישיר, YM Bridge יכול להשלים את החלפת האסימון שאושר דרך השירות שלו.

הטופס החלופי לכניסה באמצעות שם משתמש או דוא״ל וסיסמה פועל רק לאחר לחיצה על כפתור הכניסה שלו. פרטי הכניסה נשלחים פעם אחת ב־HTTPS כדי לקבל מפתח הפעלה של Last.fm, הסיסמה מנוקה מהטופס ואינה נשמרת בתוסף או נרשמת במכוון ביומני הממסר. תהליך העברת הנתונים המלא מתואר במדיניות הפרטיות.
