שליטה בחלון נפרד

מיני־נגן

פתחו חלון נפרד, שנו את גודלו מפקדים קומפקטיים לתצוגה המדגישה את העטיפה, והציבו אותו גם במסך נוסף.

מראה

בהיר וכהה

התאימו את החלונית לשולחן העבודה. הדגשות בצבעי העטיפה מציגות את אופי הרצועה הנוכחית בלי להעמיס על הממשק.

יותר מכפתורי נגן

דיווח האזנות שאפשר לעקוב אחריו

חברו את Last.fm כשתרצו. התוסף מציג את תור השליחה, מנסה לשלוח שוב דיווחים שנכשלו ומציג סטטיסטיקות האזנה מפורטות בחיבור ישיר.

  • שליחה ישירה ל־Last.fm מהדפדפן
  • גיבוי אוטומטי באמצעות Cloud relay כשהגישה הישירה אינה זמינה; ניתן להשבית אותו
  • מצבי תור, ניסיונות חוזרים ואבחון תקינות השליטה
  • קיצורי מקשים של Chrome הניתנים להתאמה

נגינה

הפעילו, השהו, דלגו למיקום אחר, שנו את עוצמת הקול, עברו בין רצועות וסמנו אהבתי או לא אהבתי כשהאפשרות זמינה דרך Yandex Music.

קובצי הרצועה המתנגנת

לאחר מתן הרשאת גישה לתיקייה, אפשר לכתוב את פרטי הרצועה הנוכחית לקובצי TXT ו־JSON ולהוסיף קובץ עטיפה מקומי עבור OBS.

פעולות על העטיפה

פתחו את העטיפה, העתיקו את כתובתה או את התמונה, והעתיקו את הטקסט אמן - רצועה מחלונית הצד או מהמיני־נגן.

יישום נלווה לבחירתכם

היישום הנלווה ל־Windows מציג חלוניות מערכת בעת החלפת רצועה. השליטה בנגן ודיווח ההאזנות נשארים באחריות התוסף.

מדריכים מעשיים

הגדירו דיווח האזנות ושמרו על פעולה תקינה

הוראות ממוקדות לחיבור Last.fm, לשימוש בממסר כגיבוי לשליחה הישירה ולפתרון עיכובים בדיווח האזנות.

01 התקנה וחיבור Last.fm אשרו גישה לחשבון, ודאו שפרטי ההפעלה נשמרו ובדקו את דיווח ההאזנה הישיר הראשון. → 02 שימוש ב־Cloud relay כשהגישה הישירה ל־Last.fm אינה זמינה גלו מתי הגיבוי מתחיל לפעול, אילו נתונים נשלחים וכיצד YM Bridge חוזר לשליחה ישירה. → 03 הבנת תור דיווחי ההאזנה ושליחה חוזרת למדו לזהות את המצבים ממתין, ממסר, ניסיון חוזר ונכשל, ולהבחין בין נגינה פעילה לרצועה שלא דווחה. → 04 הכירו את תצוגות המיני־נגן וחלונית הצד השוו בין הממשק המלא לתצוגות דיסק התקדמות, אווירה, לוח שליטה וכרטיס זכוכית. → 05 שליטה בנגן באמצעות קיצורי מקשים בחרו מיפוי מקשים נוח וקבעו אילו פקדי נגן יפעלו גם מחוץ לדפדפן. → 06 ייצוא קובצי הרצועה המתנגנת עבור OBS צרו קובצי TXT, JSON ועטיפה מקומיים שנשארים מסונכרנים עם הרצועה הנוכחית ב־Yandex Music. →

עדיפות לעבודה מקומית

השליטה בהאזנה נשארת בידיכם

ללא פרסומות או ניתוח נתוני שימוש במוצר. ההגדרות ופרטי ההפעלה של Last.fm נשמרים באחסון התוסף של Chrome.

פעולות מפורשות. גישה לקבצים וללוח ההעתקה מתבצעת רק לאחר מתן הרשאה או לחיצה על הפקודה המתאימה.

מסלולי תקשורת בשליטתכם. תחילה מתבצע ניסיון שליחה ישירה ל־Last.fm. אפשר להשבית את Cloud relay, והיישום הנלווה משמש רק לאחר הפעלת שילוב החלוניות שלו.
