Скроблінг без прямого доступу до Last.fm

Cloud relay є необов'язковим резервом для мереж без прямого доступу до API Last.fm. Його ввімкнення не замінює звичайну пряму доставку.

Пряма доставка залишається першою

Налаштування Use Cloud relay for scrobbles when direct delivery is unavailable означає саме резерв: YM Bridge спочатку звертається до API Last.fm напряму з Chrome. Relay використовується лише після придатної для резерву прямої мережевої помилки.

Коли прямий доступ працює, панель показує Delivery target: direct to Last.fm, а relay для цих скроблів не використовується.

Увімкніть резерв

  1. Відкрийте Extension settings і знайдіть Cloud relay.
  2. Увімкніть Use Cloud relay for scrobbles when direct delivery is unavailable.
  3. Під час першого використання прочитайте повідомлення про дані й натисніть Accept and keep relay fallback. До підтвердження резервна доставка не починається.

Опцію можна вимкнути будь-коли, щоб залишити лише пряму доставку.

Які дані отримує relay

Лише коли пряма доставка недоступна, метадані завершених треків і ключ сесії Last.fm надсилаються через HTTPS до керованого розробником Cloudflare Worker і пересилаються в Last.fm.

Relay навмисно не зберігає історію, ключі сесій або тіла запитів. Cloudflare як постачальник інфраструктури може обробляти IP-адресу й технічні метадані. Повний опис є в Політиці конфіденційності.

Пакети й автоматичне відновлення

Резервні скробли потрапляють у чергу й зазвичай надсилаються пакетом після 10 треків або 30 хвилин. Це зменшує трафік через Worker. Панель позначає їх як Relay і залишає видимими в черзі.

YM Bridge періодично перевіряє прямий доступ до Last.fm. Після відновлення нові доставки автоматично повертаються на прямий шлях без очищення налаштування relay.

Перевірте роботу

  • Відкрийте бічну панель і прочитайте Delivery target.
  • Відкрийте View queue, щоб побачити Relay, Retry або Failed.
  • Якщо пакет залишився після строку, один раз натисніть Retry і перевірте оновлену помилку.
  • Мітка Last.fm connected підтверджує збережену сесію, але сама не доводить доступність прямого API з поточної мережі.
