Як підключити Yandex Music до Last.fm

YM Bridge читає трек із відкритої вкладки Yandex Music і надсилає відповідні прослуховування у ваш Last.fm. Доставкою продовжує керувати розширення.

Відкрити в Chrome Web Store Підтримка
На цій сторінці Перед початком Підключіть обліковий запис Last.fm Перевірте доставку Якщо звичайний вхід недоступний

Перед початком

  • Використовуйте Chrome і тримайте Yandex Music відкритим у вкладці.
  • Установіть YM Bridge із Chrome Web Store.
  • Підготуйте обліковий запис Last.fm. Windows companion для скроблінгу не потрібний.

Підключіть обліковий запис Last.fm

  1. Відкрийте бічну панель YM Bridge, розгорніть Tools, виберіть Settings, а потім Extension settings.
  2. У розділі Last.fm setup натисніть Connect Last.fm.
  3. Дозвольте доступ на Last.fm. Розширення збереже отриманий ключ сесії у сховищі Chrome.
  4. Поверніться до панелі й переконайтеся, що Last.fm має стан connected.

Перевірте доставку

Запустіть трек у Yandex Music і відкрийте бічну панель. Мають з'явитися назва, виконавець і ціль доставки. За звичайного доступу показано direct to Last.fm.

Порожня черга може бути нормальною, поки поточний трек обробляється наживо. Після надсилання відповідного прослуховування оновиться Last delivery, а трек з'явиться в історії Last.fm.

Якщо звичайний вхід недоступний

Спочатку спробуйте Connect Last.fm. Якщо прямий API автентифікації недоступний, YM Bridge може завершити обмін схваленого токена через свій сервіс.

Альтернативна форма з ім'ям або електронною поштою та паролем працює лише після натискання кнопки. Дані одноразово надсилаються через HTTPS для отримання ключа сесії Last.fm; пароль очищається з форми, не зберігається розширенням і навмисно не журналюється relay. Повну схему описує Політика конфіденційності.
