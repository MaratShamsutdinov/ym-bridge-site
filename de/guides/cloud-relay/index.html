Zustellungsanleitung

Scrobbeln, wenn Last.fm nicht direkt erreichbar ist

Cloud relay ist ein optionaler Fallback für Netzwerke ohne direkten Zugriff auf die Last.fm-API. Seine Aktivierung ersetzt die normale direkte Zustellung nicht.

Im Chrome Web Store öffnen Datenschutzerklärung
Auf dieser Seite Direkte Zustellung bleibt an erster Stelle Fallback aktivieren Welche Daten das relay erhält Bündelung und automatische Erholung Funktion prüfen

Direkte Zustellung bleibt an erster Stelle

Die Einstellung Use Cloud relay for scrobbles when direct delivery is unavailable bedeutet genau das: YM Bridge versucht die Last.fm-API zuerst direkt aus Chrome. Das relay wird für Scrobbles nur nach einem geeigneten direkten Netzwerkfehler verwendet.

Bei gesundem Direktzugriff zeigt das Panel Delivery target: direct to Last.fm; das relay wird für diese Scrobbles nicht genutzt.

Fallback aktivieren

  1. Öffnen Sie Extension settings und suchen Sie Cloud relay.
  2. Aktivieren Sie Use Cloud relay for scrobbles when direct delivery is unavailable.
  3. Lesen Sie bei der ersten Verwendung den Datenhinweis und klicken Sie auf Accept and keep relay fallback. Vor dieser Zustimmung startet die Fallback-Zustellung nicht.

Sie können die Option jederzeit deaktivieren und nur direkte Zustellung verlangen.

Welche Daten das relay erhält

Nur wenn die direkte Zustellung nicht verfügbar ist, werden Metadaten abgeschlossener Titel und der Last.fm-Sitzungsschlüssel per HTTPS an den vom Entwickler betriebenen Cloudflare Worker gesendet und an Last.fm weitergeleitet.

Das relay speichert Hörverlauf, Sitzungsschlüssel oder Anfragetexte nicht absichtlich. Cloudflare kann als Infrastrukturanbieter IP-Adresse und technische Anfragemetadaten verarbeiten. Die vollständige Offenlegung steht in der Datenschutzerklärung.

Bündelung und automatische Erholung

Fallback-Scrobbles werden eingereiht und normalerweise nach 10 Titeln oder 30 Minuten als Paket gesendet. Das reduziert den Traffic über den Worker. Das Panel kennzeichnet solche Einträge als Relay und zeigt sie in der Warteschlange.

YM Bridge prüft regelmäßig den direkten Last.fm-Zugriff. Sobald er wieder funktioniert, kehren neue Zustellungen automatisch zum direkten Weg zurück; die relay-Einstellung muss nicht gelöscht werden.

Funktion prüfen

  • Öffnen Sie das Seitenpanel und lesen Sie Delivery target.
  • Öffnen Sie View queue, um Relay, Retry oder Failed zu sehen.
  • Bleibt ein fälliges Paket liegen, klicken Sie einmal auf Retry und prüfen Sie den aktualisierten Fehler.
  • Die Last.fm-Anzeige connected bestätigt die gespeicherte Sitzung, beweist aber nicht allein, dass die direkte API im aktuellen Netzwerk erreichbar ist.
