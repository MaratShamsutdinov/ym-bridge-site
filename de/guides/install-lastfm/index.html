Yandex Music mit Last.fm verbinden

YM Bridge liest den Titel aus einem geöffneten Yandex-Music-Tab und sendet gültige Wiedergaben an Ihr Last.fm-Konto. Die Erweiterung steuert weiterhin die Zustellung.

Im Chrome Web Store öffnen Support
Auf dieser Seite Vor dem Start Last.fm-Konto verbinden Zustellung prüfen Wenn die normale Anmeldung nicht verfügbar ist

Vor dem Start

  • Verwenden Sie Chrome und lassen Sie Yandex Music in einem Tab geöffnet.
  • Installieren Sie YM Bridge aus dem Chrome Web Store.
  • Halten Sie ein Last.fm-Konto bereit. Der Windows-Companion ist für Scrobbling nicht erforderlich.

Last.fm-Konto verbinden

  1. Öffnen Sie das YM-Bridge-Seitenpanel, klappen Sie Tools auf, wählen Sie Settings und öffnen Sie Extension settings.
  2. Klicken Sie unter Last.fm setup auf Connect Last.fm.
  3. Genehmigen Sie den Zugriff bei Last.fm. Die Erweiterung speichert den zurückgegebenen Sitzungsschlüssel im Chrome-Erweiterungsspeicher.
  4. Kehren Sie zum Panel zurück und prüfen Sie, dass Last.fm als connected angezeigt wird.

Zustellung prüfen

Starten Sie einen Titel in Yandex Music und öffnen Sie das Seitenpanel. Titel, Interpret und Zustellungsziel sollten erscheinen. Bei normalem Netzwerkzugriff lautet das Ziel direct to Last.fm.

Eine leere Warteschlange kann normal sein, solange der aktuelle Titel live verarbeitet wird. Nach einem gültigen Scrobble wird Last delivery aktualisiert und der Titel erscheint im Last.fm-Verlauf.

Wenn die normale Anmeldung nicht verfügbar ist

Versuchen Sie zuerst Connect Last.fm. Ist die direkte Authentifizierungs-API nicht erreichbar, kann YM Bridge den genehmigten Token-Austausch über seinen Dienst abschließen.

Das alternative Formular mit Benutzername oder E-Mail und Passwort wird erst nach Betätigung der Anmeldeschaltfläche verwendet. Die Zugangsdaten werden einmal per HTTPS gesendet, um einen Last.fm-Sitzungsschlüssel zu erhalten. Das Passwort wird aus dem Formular gelöscht, nicht von der Erweiterung gespeichert und vom relay nicht absichtlich protokolliert. Den vollständigen Datenfluss beschreibt die Datenschutzerklärung.
