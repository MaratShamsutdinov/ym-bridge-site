Yandex Music Now Playing in OBS anzeigen

YM Bridge hält lokale Text-, JSON- und Coverdateien mit dem aktuellen Titel synchron, damit eine OBS-Szene sie ohne entfernten Overlay-Dienst lesen kann.

Ordnerzugriff gewähren

Öffnen Sie die Seitenleiste, klappen Sie Tools auf, wählen Sie Settings und drücken Sie im Bereich Now Playing files auf Grant folder access. Wählen Sie einen eigenen Ordner, den OBS dauerhaft lesen kann.

Chrome fragt direkt nach, weil die Erweiterung keinen Ordner für Sie auswählen darf. Die Berechtigung bleibt lokal und lässt sich über Change folder ändern oder mit Disable Now Playing entfernen.

Von YM Bridge geschriebene Dateien

now-playing.txt enthält eine einfache Zeile aus Künstler und Titel für eine OBS-Textquelle. now-playing.json bietet strukturierte Metadaten für eigene Browser-Overlays. now-playing-cover.png folgt dem aktuellen Cover, wenn der Coverexport aktiviert ist.

Bei einem Titelwechsel werden die Dateien an derselben Stelle ersetzt und bleiben auf Ihrem Computer. Last.fm-Zustellung und der optionale Desktop-Companion sind davon getrennt.

Ausgabe zu OBS hinzufügen

  1. Fügen Sie eine Quelle Text (GDI+) hinzu, aktivieren Sie das Lesen aus einer Datei und wählen Sie now-playing.txt.
  2. Fügen Sie für now-playing-cover.png eine Quelle Bild hinzu.
  3. Gestalten und platzieren Sie beide Quellen in Ihrer Szene. OBS erkennt spätere Dateiänderungen, ohne dass die Erweiterung OBS steuern muss.

Nutzen Sie die JSON-Datei, wenn Ihr Overlay Künstler, Titel, Album oder Cover getrennt benötigt.

Exportstatus prüfen

Öffnen Sie Control health und lesen Sie die Zeile Now Playing files. writing - just now bestätigt eine aktuelle Änderung; permission needed bedeutet, dass Chrome den Ordner erneut freigeben muss.

Sind die Titeldaten selbst veraltet, führen Sie Repair controls aus und laden den Yandex-Music-Tab neu. Ordnerzugriff repariert keine inaktive Seitenverbindung.
