Dostarczanie

Scrobbling bez bezpośredniego dostępu do Last.fm

Cloud relay to opcjonalna ścieżka awaryjna dla sieci bez bezpośredniego dostępu do API Last.fm. Włączenie jej nie zastępuje zwykłego dostarczania bezpośredniego.

Dostarczanie bezpośrednie ma pierwszeństwo

Opcja Use Cloud relay for scrobbles when direct delivery is unavailable działa dosłownie: YM Bridge najpierw próbuje API Last.fm bezpośrednio z Chrome. Relay otrzymuje scrobble dopiero po odpowiednim błędzie połączenia bezpośredniego.

Gdy dostęp bezpośredni działa, panel pokazuje Delivery target: direct to Last.fm, a relay nie jest używany dla tych scrobbli.

Włącz ścieżkę awaryjną

  1. Otwórz Extension settings i znajdź Cloud relay.
  2. Włącz Use Cloud relay for scrobbles when direct delivery is unavailable.
  3. Przy pierwszym użyciu przeczytaj informację o danych i kliknij Accept and keep relay fallback. Do czasu akceptacji dostarczanie awaryjne nie ruszy.

Opcję można wyłączyć w dowolnym momencie, aby wymagać wyłącznie połączenia bezpośredniego.

Jakie dane otrzymuje relay

Tylko gdy dostarczanie bezpośrednie jest niedostępne, metadane ukończonych utworów i klucz sesji Last.fm są wysyłane przez HTTPS do Cloudflare Worker obsługiwanego przez dewelopera, a następnie do Last.fm.

Relay celowo nie przechowuje historii, kluczy sesji ani treści żądań. Cloudflare może przetwarzać adres IP i techniczne metadane jako dostawca infrastruktury. Pełny opis zawiera Polityka prywatności.

Pakiety i automatyczny powrót

Awaryjne scrobble trafiają do kolejki i zwykle są wysyłane pakietem po 10 utworach lub 30 minutach. Ogranicza to ruch przez Worker. Panel oznacza je jako Relay i pokazuje w kolejce.

YM Bridge okresowo sprawdza bezpośredni dostęp do Last.fm. Gdy dostęp wraca, nowe dostawy automatycznie przechodzą na ścieżkę bezpośrednią bez usuwania ustawienia relay.

Sprawdź działanie

  • Otwórz panel boczny i odczytaj Delivery target.
  • Otwórz View queue, aby zobaczyć Relay, Retry lub Failed.
  • Jeśli pakiet pozostaje po terminie, kliknij raz Retry i sprawdź zaktualizowany błąd.
  • Stan Last.fm connected potwierdza zapisaną sesję, ale sam nie dowodzi dostępności bezpośredniego API w bieżącej sieci.
