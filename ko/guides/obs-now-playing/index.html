폴더 접근 허용하기

사이드 패널에서 Tools를 펼치고 Settings를 선택한 뒤 Now Playing files 영역의 Grant folder access를 누르세요. OBS가 계속 읽을 수 있는 전용 폴더를 선택합니다.

확장 프로그램이 사용자를 대신해 폴더를 고를 수 없기 때문에 Chrome이 직접 묻습니다. 권한은 로컬에 유지되며 Change folder로 바꾸거나 Disable Now Playing으로 제거할 수 있습니다.

YM Bridge가 기록하는 파일

now-playing.txt는 OBS 텍스트 소스용 아티스트와 트랙 한 줄을 담습니다. now-playing.json은 사용자 지정 오버레이용 구조화 메타데이터를 담습니다. now-playing-cover.png는 커버 내보내기가 켜져 있을 때 현재 커버를 따라갑니다.

재생이 바뀌면 같은 위치의 파일이 교체되며 모두 사용자 컴퓨터에 남습니다. Last.fm 전송과 선택적 데스크톱 companion은 별도 기능입니다.

OBS에 출력 추가하기

  1. 텍스트 (GDI+) 소스를 추가하고 파일에서 읽기를 켠 뒤 now-playing.txt를 선택합니다.
  2. now-playing-cover.png용 이미지 소스를 추가합니다.
  3. 두 소스의 모양과 위치를 장면에서 조정하세요. 확장 프로그램이 OBS를 제어하지 않아도 OBS가 이후 파일 변경을 감지합니다.

오버레이에서 아티스트, 제목, 앨범 또는 커버를 따로 써야 하면 JSON 파일을 사용하세요.

내보내기 상태 확인하기

Control health를 열고 Now Playing files 행을 확인하세요. writing - just now는 최근 업데이트를 뜻하며 permission needed는 Chrome에서 폴더를 다시 허용해야 함을 뜻합니다.

트랙 데이터 자체가 오래된 경우 Repair controls를 실행하고 Yandex Music 탭을 새로고침하세요. 폴더 권한으로 비활성 페이지 연결을 복구할 수는 없습니다.
