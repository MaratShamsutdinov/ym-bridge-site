두 가지 제어 화면

사이드 패널은 Chrome에 붙어 Last.fm 상태, 대기열, 도구를 가까이 보여 줍니다. 미니 플레이어는 재생 제어와 커버를 위한 별도의 크기 조절 가능한 창입니다.

두 화면 모두 Yandex Music에서 재생 중인 같은 트랙을 표시합니다. 레이아웃 전환은 표시 방식만 바꾸며 재생, 좋아요, 탐색, 스크로블링은 계속 확장 프로그램이 처리합니다.

미니 플레이어 레이아웃

모든 제어가 필요하면 전체 플레이어를, 커버 중심 감상에는 Progress disc를, 커버와 추출된 색상이 이어지는 넓은 창에는 Ambient를 사용하세요.

사이드 패널 레이아웃

전체 패널은 상태와 도구를 보여 줍니다. 압축 보기는 재생 제어를 가까이 둡니다. Progress disc는 커버를 강조하고, Control deck은 조밀하고 직접적이며, Glass card는 배경 위에 제어부를 띄웁니다.

레이아웃 순환 또는 고정

오른쪽 위의 레이아웃 버튼을 눌러 전체 보기와 모든 압축 스킨을 순서대로 전환하세요. 전환 중에도 진행률과 제어는 계속 작동합니다.

한 디자인을 유지하려면 Global settings에서 Mini player compact view 또는 Side panel compact view 값을 선택하세요. 순환 동작을 유지하려면 Cycle all을 선택합니다.
