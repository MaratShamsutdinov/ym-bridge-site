Yandex Music을 Last.fm에 연결하기

YM Bridge는 열린 Yandex Music 탭의 곡을 읽고 조건을 충족한 재생을 Last.fm 계정으로 보냅니다. 전송은 계속 확장 프로그램이 관리합니다.

Chrome 웹 스토어에서 열기 지원
이 페이지의 내용 시작하기 전에 Last.fm 계정 연결 전송 확인 일반 로그인을 사용할 수 없을 때

시작하기 전에

  • Chrome을 사용하고 Yandex Music을 탭에 열어 두세요.
  • Chrome 웹 스토어에서 YM Bridge를 설치하세요.
  • Last.fm 계정을 준비하세요. 스크로블링에 Windows companion은 필요하지 않습니다.

Last.fm 계정 연결

  1. YM Bridge 사이드 패널을 열고 Tools를 펼친 뒤 Settings, Extension settings를 차례로 여세요.
  2. Last.fm setup에서 Connect Last.fm을 누르세요.
  3. Last.fm에서 접근을 승인하세요. 반환된 세션 키는 Chrome 확장 프로그램 저장소에 보관됩니다.
  4. 패널로 돌아와 Last.fm이 connected로 표시되는지 확인하세요.

전송 확인

Yandex Music에서 곡을 재생하고 사이드 패널을 여세요. 곡명, 아티스트, 전송 대상이 표시되어야 합니다. 정상적인 네트워크에서는 direct to Last.fm이 표시됩니다.

현재 곡을 실시간으로 처리하는 동안 대기열이 비어 있어도 정상입니다. 조건을 충족한 재생이 전송되면 Last delivery가 갱신되고 Last.fm 기록에 곡이 나타납니다.

일반 로그인을 사용할 수 없을 때

먼저 Connect Last.fm을 시도하세요. 직접 인증 API에 연결할 수 없으면 YM Bridge 서비스가 승인된 토큰 교환을 완료할 수 있습니다.

사용자 이름 또는 이메일과 비밀번호를 쓰는 대체 양식은 버튼을 누른 뒤에만 실행됩니다. 인증 정보는 Last.fm 세션 키를 얻기 위해 HTTPS로 한 번 전송되며, 비밀번호는 양식에서 지워지고 확장 프로그램에 저장되지 않으며 relay에도 의도적으로 기록되지 않습니다. 전체 흐름은 개인정보처리방침을 확인하세요.
