재생 버튼 그 이상

확인할 수 있는 스크로블

필요할 때 Last.fm을 연결하세요. 확장 프로그램은 전송 대기열을 표시하고 실패한 항목을 다시 시도하며 직접 연결 시 상세한 청취 통계를 제공합니다.

  • 브라우저에서 Last.fm으로 직접 전송
  • 직접 접근할 수 없을 때 Cloud relay로 자동 대체하며 비활성화 가능
  • 대기열 상태, 재시도 및 제어 진단
  • 다시 지정할 수 있는 Chrome 키보드 단축키

재생

Yandex Music에서 제공하는 경우 재생, 일시중지, 탐색, 볼륨 및 트랙 변경과 좋아요 또는 싫어요 상태를 제어할 수 있습니다.

Now Playing 파일

폴더 접근 권한을 명시적으로 부여한 후 현재 트랙을 TXT와 JSON으로 저장하고 OBS용 로컬 커버 파일을 선택적으로 추가할 수 있습니다.

커버 작업

커버를 열고 URL 또는 이미지를 복사하며 패널이나 미니 플레이어에서 아티스트 - 트랙 값을 복사할 수 있습니다.

선택적 companion

Windows companion은 트랙 변경 시 기본 알림을 추가합니다. 재생과 스크로블은 계속 확장 프로그램이 담당합니다.

실용 가이드

스크로블링을 설정하고 안정적으로 유지하세요

Last.fm 연결, 직접 전송 우선 relay 대체 경로, 지연된 스크로블 해결 방법을 안내합니다.

01 Last.fm 설치 및 연결 계정을 승인하고 저장된 세션과 첫 직접 스크로블을 확인합니다. → 02 Last.fm 직접 연결이 불가능할 때 Cloud relay 사용 대체 경로가 시작되는 조건, 전송되는 데이터, 직접 전송으로 돌아가는 방식을 확인합니다. → 03 스크로블 대기열 이해 및 재시도 현재 재생을 누락으로 오해하지 않고 Pending, Relay, Retry, Failed 상태를 읽습니다. → 04 미니 플레이어와 사이드 패널 레이아웃 살펴보기 전체 화면과 Progress disc, Ambient, Control deck, Glass card를 비교하세요. → 05 키보드 단축키로 재생 제어하기 실용적인 키 조합을 지정하고 전역으로 동작할 재생 명령을 선택하세요. → 06 OBS용 Now Playing 파일 내보내기 현재 Yandex Music 트랙과 동기화되는 TXT, JSON 및 커버 파일을 로컬에 기록합니다. →

기본적으로 로컬 처리

청취 환경은 사용자가 직접 제어합니다

광고나 제품 분석이 없습니다. 설정과 Last.fm 세션은 Chrome 확장 프로그램 저장소에 보관됩니다.

명시적 작업만 수행합니다. 파일과 클립보드 접근은 권한을 부여하거나 해당 명령을 누른 후에만 이루어집니다.

제어 가능한 네트워크 경로. 항상 Last.fm 직접 전송을 먼저 시도합니다. Cloud relay는 끌 수 있으며 companion은 알림을 활성화한 경우에만 사용됩니다.
