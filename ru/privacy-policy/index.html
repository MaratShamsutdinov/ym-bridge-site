Данные и конфиденциальность

Политика конфиденциальности

Yandex Music to Last.fm Bridge (Scrobbler). Последнее обновление: 21 июля 2026 года.

Перевод предоставлен для удобства. Если переведённая версия расходится с английской, определяющей является английская версия.

В этой политике описано, как расширение Chrome обрабатывает данные для управления Яндекс Музыкой, функций Last.fm, локального экспорта и диагностики.

Обрабатываемые данные

Расширение может обрабатывать:

  • метаданные треков Яндекс Музыки, включая исполнителя, название, альбом, URL обложки, длительность, позицию, состояние воспроизведения и состояние лайка или дизлайка;
  • время прослушивания, элементы локальной очереди скробблов, состояние повторных попыток и результаты доставки;
  • имя пользователя Last.fm, данные профиля, статистику прослушивания, ключ сессии и ответы Last.fm при подключённой учётной записи;
  • настройки расширения, выбранную тему, параметры управления и локального экспорта;
  • созданный локально ключ подписи, производный идентификатор установки, время запроса, одноразовое значение и хеш тела, используемые для аутентификации запросов к сервису YM Bridge.

Управление Яндекс Музыкой

Данные воспроизведения считываются с открытой страницы Яндекс Музыки, чтобы показывать текущий трек и выполнять запрошенные пользователем команды. Локально они хранятся только в объёме, необходимом для текущего состояния, очереди, диагностики или выбранного пользователем экспорта.

Прямой режим Last.fm

Когда Last.fm подключён и прямая доставка доступна, метаданные трека, ключ сессии Last.fm и API-запросы отправляются напрямую в Last.fm. Профиль и статистика прослушивания также запрашиваются расширением напрямую у Last.fm. Ключ сессии и кэшированное состояние расширения хранятся в хранилище расширения Chrome.

Сервис YM Bridge и необязательный Cloud relay

Расширение обращается к ym-bridge.mytunnel.us.com, чтобы получить конфигурацию приложения Last.fm и подтвердить поддерживаемую сборку расширения. Запросы содержат производный идентификатор установки, открытый ключ подписи, время, одноразовое значение, хеш тела и подпись. Сервис использует эти технические данные для аутентификации запросов, защиты от повторного воспроизведения и ограничения злоупотреблений.

После нажатия Connect Last.fm сначала выполняется попытка прямой авторизации из браузера. Если прямой API авторизации Last.fm недоступен, сервис может временно запросить токен авторизации либо обменять подтверждённый пользователем токен на ключ сессии Last.fm и вернуть его расширению. Этот резервный путь авторизации не меняет настройку Cloud relay. Worker намеренно не сохраняет токен или ключ сессии.

Если пользователь выбирает альтернативный вход по имени или адресу электронной почты и паролю, эти данные передаются по HTTPS в YM Bridge relay и однократно пересылаются в Last.fm исключительно для получения ключа сессии Last.fm. Пароль не сохраняется в хранилище расширения Chrome, очищается из формы после попытки и намеренно не сохраняется и не журналируется relay. Полученные ключ сессии и имя пользователя Last.fm сохраняются локально в хранилище расширения Chrome. Cloudflare обрабатывает запрос как поставщик инфраструктуры relay.

Cloud relay для скробблов выбран по умолчанию как резервный канал, запускается только после однократного ознакомления с использованием данных внутри расширения и может быть отключён в настройках. Расширение сначала пытается доставить данные в Last.fm напрямую. Только когда прямая доставка недоступна, метаданные завершённых треков и ключ сессии Last.fm отправляются по HTTPS в управляемый разработчиком Cloudflare Worker и пересылаются в Last.fm. Пакеты обычно отправляются после 10 треков или 30 минут, а расширение периодически проверяет доступность прямого соединения с Last.fm.

Relay намеренно не сохраняет историю прослушивания, ключи сессий Last.fm или тела запросов. Cloudflare как поставщик инфраструктуры может обрабатывать IP-адреса и технические метаданные запросов согласно собственным политикам и срокам хранения платформы.

Локальное хранение и сроки

Настройки, данные сессии Last.fm, ключи подписи, кэш профиля и статистики, элементы очереди скробблов и состояние доставки хранятся в профиле Chrome. Элементы очереди удаляются в рамках обычной доставки и управления очередью. Пользователь может удалить сессию Last.fm, отключить экспорт, очистить неудачные элементы очереди или удалить расширение, чтобы удалить его хранилище.

Экспорт файлов Now Playing

Необязательный экспорт Now Playing записывает текст трека, JSON и обложку в папку только после явного предоставления пользователем доступа. Файлы остаются на устройстве пользователя; экспорт можно отключить, а файлы удалить.

Буфер обмена

Разрешение на запись в буфер обмена используется только после прямого действия пользователя с командой Copy. Расширение может записать текст текущего трека, URL обложки или её изображение. Оно не читает содержимое буфера и не записывает в него автоматически.

Необязательный desktop companion

Необязательный desktop companion взаимодействует через localhost или 127.0.0.1 только для отображения уведомлений о треках. За доставку в Last.fm отвечает расширение.

Передача и продажа данных

Пользовательские данные не продаются. Они передаются только в объёме, необходимом для выбранной функции:

  • в Last.fm для авторизации, запросов профиля и статистики, обновлений now playing и скробблинга;
  • в инфраструктуру Cloudflare для запросов к сервису YM Bridge и необязательной доставки через relay;
  • локальному desktop companion, когда пользователь явно включает уведомления о треках;
  • в локальные файлы или буфер обмена после явного действия пользователя.

Аналитика и реклама

Расширение не содержит рекламных SDK, поведенческого трекинга или продуктовой аналитики. Данные не используются для рекламы, оценки платёжеспособности или несвязанного профилирования. Chrome Web Store может предоставлять издателю агрегированную аналитику страницы расширения в магазине; это не добавляет аналитический код в расширение.

Безопасность

Удалённые запросы используют HTTPS. Защищённые конечные точки YM Bridge требуют подписанных запросов и проверяют время, одноразовое значение, идентификатор расширения и лимиты частоты. Ни одна мера не гарантирует абсолютной защиты, но эти проверки ограничивают несанкционированные и повторно воспроизведённые запросы.

Ограниченное использование

Использование информации, полученной через API Google, соответствует Политике пользовательских данных Chrome Web Store, включая требования Limited Use. Данные используются только для предоставления или улучшения заявленных пользовательских функций расширения.
