Как подключить Яндекс Музыку к Last.fm

YM Bridge считывает трек из открытой вкладки Яндекс Музыки и отправляет подходящие прослушивания в ваш аккаунт Last.fm. Доставкой всегда управляет расширение.

Открыть в Chrome Web Store Поддержка
На этой странице Перед началом Подключите аккаунт Last.fm Проверьте доставку Если обычный вход недоступен

Перед началом

  • Используйте Chrome и держите Яндекс Музыку открытой во вкладке.
  • Установите YM Bridge из Chrome Web Store.
  • Подготовьте аккаунт Last.fm. Windows companion для скробблинга не нужен.

Подключите аккаунт Last.fm

  1. Откройте боковую панель YM Bridge, разверните Tools, выберите Settings, затем откройте Extension settings.
  2. В разделе Last.fm setup нажмите Connect Last.fm.
  3. Разрешите доступ на Last.fm. Полученный ключ сессии сохранится в хранилище расширения Chrome.
  4. Вернитесь в панель и убедитесь, что Last.fm отмечен как connected.

Проверьте доставку

Запустите трек в Яндекс Музыке и откройте боковую панель. Должны появиться название, исполнитель и путь доставки. При обычном доступе к сети указано direct to Last.fm.

Пустая очередь может быть нормой, пока текущий трек обрабатывается в реальном времени. После отправки подходящего прослушивания обновится Last delivery, а трек появится в истории Last.fm.

Если обычный вход недоступен

Сначала попробуйте Connect Last.fm. Если прямой API авторизации недоступен, YM Bridge может завершить обмен подтверждённого токена через свой сервис.

Альтернативная форма с именем или электронной почтой и паролем срабатывает только после нажатия кнопки входа. Данные однократно отправляются по HTTPS для получения ключа сессии Last.fm, пароль очищается из формы, не сохраняется расширением и намеренно не журналируется relay. Полная схема описана в Политике конфиденциальности.
