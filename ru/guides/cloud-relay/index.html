Скробблинг при недоступности прямого доступа к Last.fm

Cloud relay служит необязательным резервом для сетей, из которых API Last.fm недоступен напрямую. Его включение не заменяет обычную прямую доставку.

Прямая доставка остаётся первой

Настройка Use Cloud relay for scrobbles when direct delivery is unavailable означает именно резерв: YM Bridge сначала обращается к API Last.fm напрямую из Chrome. Relay используется для скробблов только после сетевой ошибки, подходящей для резервной доставки.

Когда прямой доступ исправен, панель показывает Delivery target: direct to Last.fm, а relay для этих скробблов не используется.

Включите резервный путь

  1. Откройте Extension settings и найдите раздел Cloud relay.
  2. Включите Use Cloud relay for scrobbles when direct delivery is unavailable.
  3. При первом использовании прочитайте уведомление об обработке данных и нажмите Accept and keep relay fallback. До подтверждения резервная доставка не запускается.

Настройку можно отключить в любой момент, чтобы оставить только прямую доставку.

Какие данные получает relay

Только при недоступности прямой доставки метаданные завершённых треков и ключ сессии Last.fm отправляются по HTTPS в управляемый разработчиком Cloudflare Worker и пересылаются в Last.fm.

Relay намеренно не сохраняет историю прослушивания, ключи сессий или тела запросов. Cloudflare как поставщик инфраструктуры может обрабатывать IP-адрес и технические метаданные запроса. Полное описание приведено в Политике конфиденциальности.

Пакеты и автоматическое восстановление

Резервные скробблы попадают в очередь и обычно отправляются пакетом после 10 треков или 30 минут. Так уменьшается трафик через Worker. Панель помечает такие элементы как Relay и показывает их в очереди.

YM Bridge периодически проверяет прямой доступ к Last.fm. После восстановления новые отправки автоматически возвращаются на прямой путь, отключать настройку relay не требуется.

Проверьте работу

  • Откройте боковую панель и посмотрите Delivery target.
  • Откройте View queue, чтобы увидеть состояния Relay, Retry или Failed.
  • Если срок отправки пакета прошёл, нажмите Retry один раз и проверьте обновлённую ошибку.
  • Метка Last.fm connected подтверждает сохранённую сессию, но сама по себе не доказывает доступность прямого API Last.fm из текущей сети.
