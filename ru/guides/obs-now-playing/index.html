Добавьте Now Playing Яндекс Музыки в OBS

YM Bridge синхронизирует локальные текстовый, JSON- и графический файлы с текущим треком, чтобы сцена OBS читала их без удалённого сервиса оверлеев.

Предоставьте доступ к папке

Откройте боковую панель, разверните Tools, выберите Settings и нажмите Grant folder access в разделе Now Playing files. Выберите отдельную папку, которую OBS сможет постоянно читать.

Chrome запрашивает выбор напрямую, потому что расширение не может выбрать папку за пользователя. Разрешение остаётся локальным; его можно изменить через Change folder или отключить через Disable Now Playing.

Какие файлы создаёт YM Bridge

now-playing.txt содержит простую строку с исполнителем и треком для текстового источника OBS. В now-playing.json находятся структурированные метаданные для собственных оверлеев. now-playing-cover.png обновляет текущую обложку, если её экспорт включён.

При смене трека файлы заменяются на месте и остаются на вашем компьютере. Доставка в Last.fm и необязательный desktop companion работают отдельно.

Добавьте файлы в OBS

  1. Добавьте источник Text (GDI+), включите чтение из файла и выберите now-playing.txt.
  2. Добавьте источник Image для now-playing-cover.png.
  3. Настройте стиль и расположение источников в сцене. OBS увидит последующие обновления без прямого управления со стороны расширения.

JSON-файл подходит оверлеям, которым нужны отдельные значения исполнителя, названия, альбома или обложки.

Проверьте состояние экспорта

Откройте Control health и найдите строку Now Playing files. Значение writing - just now подтверждает недавнее обновление, а permission needed означает, что Chrome нужно снова предоставить папку.

Если устарели сами данные трека, запустите Repair controls и перезагрузите вкладку Яндекс Музыки. Разрешение на папку не исправляет неактивное подключение к странице.
