在 OBS 中显示 Yandex Music Now Playing

YM Bridge 会让本地文本、JSON 和封面文件与当前曲目保持同步，使 OBS 场景无需远程叠加层服务即可读取它们。

授予文件夹访问权限

在侧边栏中展开 Tools，选择 Settings，然后在 Now Playing files 区域点击 Grant folder access。选择一个 OBS 可以持续读取的专用文件夹。

扩展程序不能代替您选择文件夹，因此 Chrome 会直接请求确认。权限仅保留在本地，可通过 Change folder 更改，或通过 Disable Now Playing 移除。

YM Bridge 写入的文件

now-playing.txt 为 OBS 文本源保存一行艺术家和曲目名称。now-playing.json 为自定义叠加层提供结构化元数据。启用封面导出后，now-playing-cover.png 会随当前封面更新。

曲目变化时，同一位置的文件会被替换，并始终留在您的计算机上。Last.fm 传送和可选的桌面 companion 是独立功能。

将输出添加到 OBS

  1. 添加 Text (GDI+) 源，启用从文件读取，然后选择 now-playing.txt。
  2. 为 now-playing-cover.png 添加一个 Image 源。
  3. 在场景中设置两个源的样式和位置。无需扩展程序控制 OBS，OBS 也会检测后续文件变化。

如果叠加层需要分别使用艺术家、标题、专辑或封面，请使用 JSON 文件。

检查导出状态

打开 Control health，查看 Now Playing files 一行。writing - just now 表示刚刚完成更新；permission needed 表示需要在 Chrome 中重新授权文件夹。

如果曲目数据本身已过期，请运行 Repair controls 并重新加载 Yandex Music 标签页。文件夹权限无法修复失效的页面连接。
