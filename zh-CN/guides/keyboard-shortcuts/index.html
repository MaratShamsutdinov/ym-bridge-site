使用键盘控制 Yandex Music

Chrome 允许为 YM Bridge 命令指定自定义按键，并选择哪些核心播放控制可在浏览器外使用。

在 Chrome 应用商店中打开 支持

打开 Chrome 快捷键设置

在地址栏输入 chrome://extensions/shortcuts。找到 Yandex Music to Last.fm Bridge，点击命令旁的铅笔，然后按下所需组合键。

该页面和快捷键保存均由 Chrome 管理。YM Bridge 无法在后台替换已被占用的按键。

实用的按键布局

数字布局容易记忆：7 为上一首，8 为播放或暂停，9 为下一首，4 和 6 为后退和前进。使用 L 表示喜欢，使用 X 表示不喜欢。

加入 Ctrl + Shift 可减少与普通输入和常用浏览器命令的冲突。音量可设置为 Ctrl + Shift + 向上箭头和向下箭头。

全局或仅限 Chrome

如果希望在其他应用处于前台时也能操作，请将 Play / pause、Next track 和 Previous track 设为 Global。喜欢、不喜欢、定位进度和音量可保留为 In Chrome。

Yandex Music 标签页仍需保持打开。Global 只改变快捷键可被接收的范围，不会启动音乐网站。

解决快捷键冲突

如果 Chrome 拒绝某个组合键或按下后没有反应，可能是其他扩展程序或操作系统已占用该按键。请选择其他按键并在播放时测试。

如果快捷键已保存但曲目没有响应，请打开 Tools 并运行 Control health。页面连接过期时，使用 Repair controls 或重新加载 Yandex Music 标签页。
