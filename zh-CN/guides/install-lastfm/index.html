将 Yandex Music 连接到 Last.fm

YM Bridge 会读取已打开的 Yandex Music 标签页中的曲目，并将符合条件的收听记录发送到您的 Last.fm 账户。传输仍由扩展程序管理。

在 Chrome 应用商店中打开 支持
本页内容 开始之前 连接 Last.fm 账户 验证传输 无法使用常规登录时

开始之前

  • 使用 Chrome，并在标签页中保持 Yandex Music 打开。
  • 从 Chrome 应用商店安装 YM Bridge。
  • 准备好 Last.fm 账户。播放记录提交不需要 Windows companion。

连接 Last.fm 账户

  1. 打开 YM Bridge 侧边栏，展开 Tools，选择 Settings，然后打开 Extension settings。
  2. 在 Last.fm setup 中点击 Connect Last.fm。
  3. 在 Last.fm 上批准访问。扩展程序会把返回的会话密钥保存在 Chrome 扩展程序存储中。
  4. 返回面板，确认 Last.fm 显示为 connected。

验证传输

在 Yandex Music 中播放曲目并打开侧边栏。应显示曲名、艺术家和传输目标。网络正常时，目标为 direct to Last.fm。

当前曲目正在实时处理时，队列为空也可能是正常状态。符合条件的收听记录发送后，Last delivery 会更新，曲目也会出现在 Last.fm 历史中。

无法使用常规登录时

请先尝试 Connect Last.fm。如果无法访问直接认证 API，YM Bridge 可以通过其服务完成已批准令牌的交换。

只有按下按钮后，使用用户名或电子邮件和密码的备用表单才会运行。凭据仅通过 HTTPS 发送一次以获取 Last.fm 会话密钥；密码会从表单中清除，不由扩展程序保存，也不会被 relay 有意记录。完整流程请查看隐私政策。
