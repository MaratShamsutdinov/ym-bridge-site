操作ガイド

キーボードで Yandex Music を操作する

Chrome では YM Bridge の各コマンドに好きなキーを割り当て、主要な再生操作をブラウザー外でも有効にするか選べます。

Chrome ウェブストアで開く サポート
このページの内容 Chrome のショートカット設定を開く 覚えやすいキー配置 グローバルまたは Chrome 内のみ 競合を解決する

Chrome のショートカット設定を開く

アドレスバーに chrome://extensions/shortcuts と入力します。Yandex Music to Last.fm Bridge を見つけ、コマンド横の鉛筆を押して、使いたいキーの組み合わせを入力します。

この画面と割り当ての保存は Chrome が管理します。YM Bridge が使用中のキーを自動で置き換えることはありません。

覚えやすいキー配置

数字を使うと覚えやすくなります。7 は前の曲、8 は再生または一時停止、9 は次の曲、4 と 6 は巻き戻しと早送りです。Like は L、Dislike は X にします。

Ctrl + Shift を加えると、通常の入力や一般的なブラウザー操作との競合を減らせます。音量には Ctrl + Shift + 上 と 下 を使えます。

グローバルまたは Chrome 内のみ

別のアプリを使用中でも操作したい場合は、再生/一時停止、次へ、前へを Global にします。Like、Dislike、シーク、音量は、必要になるまで In Chrome のままにできます。

Yandex Music のタブは開いている必要があります。Global はキーを受け付ける範囲を変えるだけで、音楽サイトを起動する機能ではありません。

競合を解決する

Chrome が組み合わせを受け付けない、または反応しない場合は、別の拡張機能や OS がそのキーを使用している可能性があります。別のキーを選び、再生中に一度テストしてください。

設定は受け付けられたのに曲が反応しない場合は、Tools から Control health を実行します。ページ接続が古いときは Repair controls を使うか、Yandex Music のタブを再読み込みします。
