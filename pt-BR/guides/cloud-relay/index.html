Guia de entrega

Faça scrobbling sem acesso direto ao Last.fm

Cloud relay é um fallback opcional para redes que não alcançam diretamente a API do Last.fm. Ativá-lo não substitui a entrega direta normal.

Abrir na Chrome Web Store Política de Privacidade

A entrega direta continua em primeiro lugar

A opção Use Cloud relay for scrobbles when direct delivery is unavailable é literal: o YM Bridge tenta primeiro a API do Last.fm pelo Chrome. O relay só recebe scrobbles após uma falha direta de rede compatível com fallback.

Quando o acesso direto funciona, o painel mostra Delivery target: direct to Last.fm e o relay não é usado nesses scrobbles.

Ative o fallback

  1. Abra Extension settings e encontre Cloud relay.
  2. Ative Use Cloud relay for scrobbles when direct delivery is unavailable.
  3. No primeiro uso, leia o aviso sobre dados e pressione Accept and keep relay fallback. O fallback não começa antes dessa aceitação.

Você pode desativar a opção a qualquer momento para exigir somente a entrega direta.

O que o relay recebe

Somente quando a entrega direta está indisponível, os metadados das faixas concluídas e a chave de sessão do Last.fm são enviados por HTTPS ao Cloudflare Worker operado pelo desenvolvedor e encaminhados ao Last.fm.

O relay não retém intencionalmente histórico, chaves de sessão nem corpos de solicitação. A Cloudflare pode processar o endereço IP e metadados técnicos como provedora de infraestrutura. A descrição completa está na Política de Privacidade.

Lotes e recuperação automática

Os scrobbles de fallback entram na fila e normalmente são enviados em lote após 10 faixas ou 30 minutos. Isso reduz o tráfego pelo Worker. O painel marca esses itens como Relay e os mantém visíveis na fila.

O YM Bridge verifica periodicamente o acesso direto ao Last.fm. Quando ele volta, novas entregas retornam automaticamente ao caminho direto sem remover a opção de relay.

Verifique o funcionamento

  • Abra o painel lateral e leia Delivery target.
  • Abra View queue para ver Relay, Retry ou Failed.
  • Se um lote continuar depois do prazo, pressione Retry uma vez e examine o erro atualizado.
  • O rótulo connected confirma uma sessão salva do Last.fm, mas não prova sozinho que a API direta está acessível na rede atual.
